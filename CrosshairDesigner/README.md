# Crosshair Designer

一个适用于 Windows 的虚拟准星设计软件，具有现代化的 Windows UI 界面。

## 功能特性

- **准星开关控制**
  - 右上角摇杆式切换开关
  - 快捷键 `Shift + Alt + Z` 快速开关准星

- **准星设计器**
  - 左侧坐标轴预览区域
    - 实时显示准星效果
    - 支持鼠标滚轮缩放 (10% - 500%)
    - 支持拖拽平移视图
    - 显示当前鼠标坐标位置
  
  - 右侧设置面板
    - **样式选择**: Cross(交叉)、Dot(点)、Circle(圆)、Plus(加号)、Custom(自定义)
    - **颜色选择**: 完整的颜色选择器
    - **大小调节**: 1-50 像素
    - **粗细调节**: 1-20 像素
    - **透明度调节**: 10%-100%
    - **间距调节**: 0-50 像素 (适用于 Cross 和 Plus 样式)
    - **中心点**: 可选显示中心点
    - **轮廓**: 可选显示黑色轮廓增强可见性
    - **重置**: 一键恢复默认设置

## 技术栈

- .NET 8.0
- WPF (Windows Presentation Foundation)
- Windows Forms (用于颜色对话框)

## 系统要求

- Windows 10/11
- .NET 8.0 Runtime

## 构建方法

```bash
cd CrosshairDesigner
dotnet build
```

## 运行方法

```bash
dotnet run
```

## 使用说明

1. 启动应用后，在左侧预览区查看准星效果
2. 在右侧面板调整准星的样式、颜色、大小等参数
3. 点击右上角的开关或使用 `Shift + Alt + Z` 快捷键开启/关闭屏幕准星
4. 开启后，准星将显示在屏幕中央，覆盖在所有窗口之上

## 注意事项

- 应用需要管理员权限才能注册全局热键
- 准星覆盖层始终位于最顶层，确保在游戏中也能看到
